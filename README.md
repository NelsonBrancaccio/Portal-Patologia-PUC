# Portal Patologia PUC

Site de referência em Patologia — PUC-SP Sorocaba.

- Gerado com [Astro](https://astro.build)
- Conteúdo em Markdown, em `src/content/topicos/`
- Edição sem código via `/admin` (Decap CMS), depois de configurar Identity + Git Gateway no Netlify

## Rodar localmente (opcional)

```
npm install
npm run dev
```

## Publicar

Basta conectar este repositório ao Netlify (build command `npm run build`, publish directory `dist`). Veja o guia "Portal de Medicina — Passo a Passo de Implantação" para o passo a passo completo.
